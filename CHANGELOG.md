# Changelog

## 1.3.0

Add native `restart` and `shutdown` APIs so apps using `RecordOnStart = false` can start/stop capture without the browser API. Bump default `FS_VERSION` to 1.73.2.

Fix plugin id mismatch (`fullstory-cordova-plugin` → `@fullstory/cordova-plugin`) and add cordova-ios 8 compatibility.

## 1.2.3

Support android-packageName in config.xml.
